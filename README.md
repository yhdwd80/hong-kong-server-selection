## 免备案不等于一定快：线路决定国内访问体验

香港机房离大陆近，但“近”不等于“快”。回程路由怎么走，直接决定晚高峰会不会卡。以野草云公开的线路分档为例，同样标“BGP”，实际差别是这样的：

- **优质 BGP**：电信回程走 CMI，联通在 CU、NTT、CMI 之间均衡，移动走 Level3，国际方向择优选路。三网都有覆盖，兼顾海外。
- **精品 BGP**：电信回程 CU，联通回程 CU，移动回程 CMI，三网都走骨干直连，晚高峰波动小。适合纯国内访问、对延迟敏感的业务。
- **国际 BGP**：不含 CMI 和 CU，国际方向择优选路，国内方向延迟明显更高。只适合纯出海业务。

这条分层规则对判断任何一家香港机都成立。再看雨云香港五区的实测数据：第三方测评记录的三网平均延迟 139ms，上海移动最低 34ms；去程电信和联通绕日本，移动直连香港；回程电信走 163 线路、联通绕美国、移动绕日本。

这说明什么？便宜的大带宽香港机，通常把钱花在带宽上，回程不做深度优化。移动用户体验最好，电信和联通会绕路。如果你做的是外贸站、下载站、图床、API 中转这类对带宽敏感、对几十毫秒延迟不敏感的业务，这个组合是划算的；如果做的是国内用户高频访问的资讯站或后台系统，就得把线路这一项放在价格前面。

## 低价套餐的四个隐藏成本

**第一，续费价可能翻倍。** 市场上两种模式并存：一种是首年低价、续费回到原价，国内备案机低价款续费普遍回到 80-130 元/月，第二年成本直接翻倍；另一种是续费同价，野草云的轻量年付系列和恒创的活动套餐都写明续费同价。下单前把续费价拉到和首年价一起看，才算真实年成本。

**第二，限速和限量是两种商品。** 同样标 200Mbps，野草云的月付档是 200Mbps 不限流量、30 元/月起；轻量年付档则是每月 500-1900GB、超量限速到 1Mbps。雨云的规则是流量用完降到 5Mbps，再买流量包恢复。做视频、下载、图床这类大流量业务，选限量档等于给自己埋雷。

**第三，一些硬限制只写在条款里。** 野草云开 25 端口要交 150 元保证金；恒创的 1核1G、1核2G 低配换 IP 要收费，日本节点原生 IP 需联系客服额外付 200 元/月/个；野草云不保证 IPv4 是香港原生 IP。这些不影响大多数人，但做邮件服务、多账号业务、流媒体解锁的，得提前问清。

**第四，走备案路线时服务器照常计费。** 备案本身免费，但审核由各省通信管理局执行，首次备案通常 1-2 周，这段时间服务器空转也在扣钱。免备案省下的就是这段时间和这笔钱。
